# Product

BusinessPulse (Inventa Studio): Business Intelligence and Decision Execution Platform. Tagline: See what matters. Act on it. Measure the impact.

Lifecycle every feature must serve: **Detect → Understand → Decide → Execute → Verify**.

- Stage 1 is a functional, deployable Proof of Value for a prospective client, built as the foundation of the production MVP. Not a throwaway prototype.
- Real workflows only: no fake buttons, hardcoded results, or simulated AI shown as real. Seeded fictional data must pass through real workflows.
- Roles: Owner/Admin, Manager, Staff. One company, Sales department.
- AI assists; deterministic code is authoritative; humans approve assignments.
- Details: `docs/product-vision.md`, `docs/stage-1-scope.md`, `docs/demo-scenario.md`. Vocabulary: issue, rule evaluation, brief, meeting, task draft, task, outcome, baseline evidence.
